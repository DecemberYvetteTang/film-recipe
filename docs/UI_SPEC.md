# Film Recipe UI 规范

## 1. 规范目标

这份规范用于约束第一版移动端 UI 的字体、间距和组件样式，避免设计稿和后续开发中出现 padding、字号、圆角、阴影各自为政的问题。

参考素材来自 `UI 参考素材/ElevenLabs.jpg` 和 `UI 参考素材/Photoroom iOS 14.png`。Film Recipe 只吸收它们的控件秩序：大圆角、固定高度、悬浮底栏、清楚留白，不照搬偏 AI 工具产品的强商业感。

## 2. 基础网格

- 设计基准：390px 手机宽度。
- 页面水平边距：24px。
- 内容安全底部：底部导航上方至少保留 92px 可滚动空白。
- 间距采用 4pt 系统：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40。

常用间距：

```text
xs  4px   图标与文字的微间距
sm  8px   标签、缩略图、紧密表单项
md  12px  控件内部横向 padding、卡片文字区
lg  16px  普通模块内部 padding
xl  20px  模块与模块之间
2xl 24px  页面边距、主要区块间距
3xl 32px  大块内容间距
```

## 3. 字体

第一版优先系统字体，避免额外字体加载。

```text
标题 / 气质文字:
  ui-serif, "Songti SC", "Noto Serif CJK SC", serif

正文 / 控件:
  Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif

参数值:
  "SF Mono", "Roboto Mono", ui-monospace, monospace
```

字号规范：

| 用途 | 字号 | 行高 | 字重 | 说明 |
| --- | ---: | ---: | ---: | --- |
| App 标题 | 28px | 34px | 700 | 品牌入口页或强标题，少用 |
| 页面标题 | 24px | 32px | 700 | 新建页、详情页标题 |
| 配方标题 | 20px | 28px | 700 | 详情页配方名 |
| 模块标题 | 17px | 24px | 650 | 参数分组、页面区块标题 |
| 正文 | 15px | 22px | 400 | 普通说明、备注 |
| 控件文字 | 14px | 20px | 600 | 按钮、Tab、筛选标签 |
| 参数名 | 13px | 20px | 500 | 相机菜单参数 label |
| 参数值 | 14px | 22px | 500 | 使用等宽字体 |
| 辅助文字 | 12px | 17px | 400 | 数量、来源标注、提示 |
| 底部导航文字 | 11px | 14px | 600 | 固定，不随屏幕缩放 |

规则：

- 字距固定为 0，不使用负字距。
- 参数值不压缩行高，保证外出时边看手机边调相机。
- 卡片标题最多两行，超过隐藏；参数详情不截断核心参数值。

## 4. 间距与布局

页面：

- 顶部内容从 y=24px 开始。
- 快查页品牌 Tab 到第一组筛选标签间距：16px。
- 筛选区组内行距：10px。
- 筛选区到样张瀑布流间距：20px。
- 详情页大图到缩略图间距：12px。
- 详情页信息区到参数区间距：24px。
- 新建页表单分组间距：24px。

模块：

- 普通模块横向宽度：342px。
- 普通模块内部 padding：16px。
- 紧凑胶囊内部横向 padding：12px。
- 表单输入高度：48px。
- 小按钮高度：34px。
- 默认按钮高度：44px。

底部导航：

- 宽度：342px。
- 高度：64px。
- 左右位置：x=24px。
- 底部距离：22px。
- 内部上下 padding：8px。
- 三个入口等分，每个点击区约 96px。
- 选中态胶囊：96px x 48px，位于导航内部，顶部/底部各 8px。

## 5. 圆角

```text
4px   细小标记、进度条、手写下划线
8px   样张卡片、缩略图、图片容器
12px  普通信息模块、参数分组
16px  表单输入、小面板
17px  34px 小按钮
22px  44px Tab / 筛选胶囊
24px  大按钮、上传区
32px  悬浮底部导航
```

规则：

- 样张卡片圆角不超过 8px，避免照片变成玩具感。
- 筛选标签、Tab、底部导航可以使用全圆角。
- 不使用卡片套卡片；需要区分层级时用留白、细边框和分割线。

## 6. 阴影与边框

边框：

- 浅边框：`#D9D4C8`，1px，用于 Tab、筛选、输入框。
- 分割线：`#E3DFD3`，1px，用于参数组之间。
- 图片边框默认不用，只有浅色图片需要 `#D9D4C8` 1px。

阴影：

```text
Nav float:
  0 18px 34px rgba(20, 18, 14, 0.16)

Soft control:
  0 10px 22px rgba(20, 18, 14, 0.10)

Photo card:
  默认无阴影，依靠图片和文字层级区分
```

规则：

- 阴影只给悬浮导航、顶部 Tab、重要弹层使用。
- 普通卡片不用阴影，保持摄影笔记的安静感。
- 半透明导航底色使用 `rgba(255, 253, 248, 0.78)`，保留轻微玻璃感。

## 7. 组件

### 品牌 Tab

- 容器：342px x 44px，圆角 22px。
- 容器背景：`rgba(250, 248, 241, 0.86)`。
- 选中态：约 164px x 32px，圆角 16px。
- 选中 Fuji：`#2F5F50` 背景，白色文字。
- 未选中：透明背景，`#6F716B` 文字。

### 筛选标签

- 高度：32px。
- 圆角：16px。
- 横向 padding：12px。
- 选中态：深色或品牌色背景，白色文字。
- 未选中：透明或浅纸色背景，浅边框。

### 按钮

- 小按钮：34px 高，圆角 17px，横向 padding 14px。
- 默认按钮：44px 高，圆角 22px，横向 padding 18px。
- 主按钮使用品牌色或 Ink Black。
- 次按钮使用浅纸色背景 + 1px 边框。

### 样张卡片

- 两列瀑布流，列宽 160px，列间距 22px。
- 图片圆角：8px。
- 图片到标题：12px。
- 标题：15px / 22px / 700。
- 状态：12px / 17px / 700，常用用 Fuji Green，想试用 Ricoh Red。
- 标签：12px / 17px / 400，最多一行。

### 参数列表

- 分组标题：17px / 24px / 650。
- 分组之间：24px。
- 参数项之间：14px。
- 参数名：13px / 20px，Viewfinder Gray。
- 参数值：14px / 22px，等宽字体，Ink Black。
- 不展示空参数。
- 详情页不展示来源和参数截图入口，只保留最终参数。

### 底部导航

- 容器：342px x 64px，圆角 32px。
- 位置：左右 24px，底部 22px。
- 背景：`rgba(255, 253, 248, 0.78)`。
- 边框：1px `rgba(255, 255, 255, 0.78)`。
- 阴影：`0 18px 34px rgba(20, 18, 14, 0.16)`。
- 选中态：96px x 48px，圆角 24px，背景 `#F3EFE6`。
- 图标：20px 视觉尺寸。
- 文字：11px / 14px / 600。
- 图标和文字间距：4px。

## 8. 页面级规则

### 快查页

- 顶部使用 Fuji / Ricoh Tab，不放左上角品牌卡。
- 清空筛选位于筛选 / 排序区域，不能与品牌 Tab 挤在一起。
- 样张瀑布流优先于参数信息，卡片内不展示完整参数。

### 详情页

- 只保留样张、配方基本信息、参数、备注。
- 不展示「来源」模块。
- 不展示「预览参数截图」入口。
- OCR 或手动录入方式不作为详情页信息。

### 新建 / 编辑页

- 「效果样张」用于展示配方风格。
- 「读取参数截图」只用于 OCR 辅助录入，不作为详情页来源证据。
- 默认展开第一个参数分组，其余分组折叠。

## 9. 开发映射建议

- CSS spacing token：`--space-4` 到 `--space-40`。
- Radius token：`--radius-photo`, `--radius-panel`, `--radius-pill`, `--radius-nav`。
- Shadow token：`--shadow-soft`, `--shadow-nav`。
- Type token：`--text-body`, `--text-caption`, `--text-param-value`。
