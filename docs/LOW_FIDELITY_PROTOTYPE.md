# Film Recipe 第一版低保真原型

## 1. 原型目标

第一版原型只验证一个核心问题：

> 用户出门拍照时，能不能先选品牌，再通过场景、题材和样张，在 10 秒内找到想用的配方。

本原型不验证最终视觉风格，不包含高保真 UI，不追求完整交互动效。它用于确认页面结构、信息优先级和主要操作路径。

## 2. 页面范围

第一版包含 5 个核心页面：

- 品牌入口页
- 配方快查页
- 配方详情页
- 新建 / 编辑配方页
- 备份页

## 3. 全局导航

手机端底部导航建议保留 3 个入口：

- 快查
- 新建
- 备份

品牌选择不是底部导航项，而是快查页的第一层上下文。用户可以在快查页顶部切换品牌。

第一版默认进入品牌入口页，不记忆用户上一次选择的品牌。

```text
┌─────────────────────┐
│ Film Recipe          │
│ 相机直出配方快查笔记 │
├─────────────────────┤
│ 当前品牌：富士  v    │
├─────────────────────┤
│ 页面内容             │
├─────────────────────┤
│ 快查     新建     备份 │
└─────────────────────┘
```

## 4. 页面一：品牌入口页

### 页面目标

让用户先确定当前使用的相机品牌，减少后续筛选和参数模板干扰。

### 触发场景

- 第一次打开应用。
- 用户在快查页切换品牌。
- 用户新建配方时选择品牌。

### 信息优先级

1. 品牌：富士 / 理光。
2. 当前已适配机型。
3. 品牌下已有配方数量。

### 低保真结构

```text
┌─────────────────────┐
│ Film Recipe          │
│ 今天用哪台相机？     │
├─────────────────────┤
│ ┌─────────────────┐ │
│ │ 富士             │ │
│ │ X-H2 / X100V     │ │
│ │ X-E5             │ │
│ │ 12 个配方        │ │
│ └─────────────────┘ │
│ ┌─────────────────┐ │
│ │ 理光             │ │
│ │ GR IIIx          │ │
│ │ 5 个配方         │ │
│ └─────────────────┘ │
└─────────────────────┘
```

### 已确认决策

- 第一次打开默认停在品牌入口页。
- 第一版不记忆上一次选择的品牌。
- 品牌卡片可以显示配方数量，空数据时显示 0 个配方。

## 5. 页面二：配方快查页

### 页面目标

通过少量筛选和样张瀑布流，快速选择配方。

### 信息优先级

1. 当前品牌。
2. 场景筛选。
3. 题材筛选。
4. 风格筛选。
5. 样张瀑布流。
6. 常用 / 想试状态。

### 低保真结构

```text
┌─────────────────────┐
│ 富士           切换  │
├─────────────────────┤
│ 场景                │
│ 晴天 阴天 正午 蓝调  │
│ 夜晚 室内            │
├─────────────────────┤
│ 题材                │
│ 街拍 人像 风景 旅行  │
│ 日常                │
├─────────────────────┤
│ 风格                │
│ 日系 胶片 冷调 暖调  │
│ 高对比 低饱和 电影感 │
├─────────────────────┤
│ 瀑布流样张           │
│ ┌──────┐ ┌──────┐   │
│ │ 图片 │ │ 图片 │   │
│ │ 常用 │ │ 想试 │   │
│ │ 阴天 │ │ 蓝调 │   │
│ └──────┘ └──────┘   │
│ ┌──────┐ ┌──────┐   │
│ │ 图片 │ │ 图片 │   │
│ │ 常用 │ │ 想试 │   │
│ └──────┘ └──────┘   │
├─────────────────────┤
│ 快查     新建     备份 │
└─────────────────────┘
```

### 配方卡片字段

卡片上只展示决策必要信息：

- 封面样张。
- 配方名。
- 状态：常用 / 想试。
- 2 到 4 个标签。
- 样张来源标记：我拍摄 / 作者参考图。

卡片上不展示完整参数，避免快查页变成参数表。

### 空状态

```text
还没有富士配方

可以先上传截图保存网上看到的参数，
也可以手动新建一条自己的配方。

[新建配方]
```

### 已确认决策

- 风格标签默认折叠，只保留一个可见标签入口，其余通过展开查看。
- 第一版不加入模拟数据，空数据时展示空状态。

### 待确认点

- 快查页筛选是否需要「清空筛选」按钮。
- 是否需要「常用优先」排序。

## 6. 页面三：配方详情页

### 页面目标

用户确认样张风格后，可以清楚查看相机菜单式参数，方便边看手机边调相机。

### 信息优先级

1. 样张。
2. 配方名和状态。
3. 适配品牌 / 机型。
4. 标签。
5. 相机菜单式参数。
6. 备注。
7. 原始截图。

### 低保真结构

```text
┌─────────────────────┐
│ < 返回   复制参数  编辑 │
├─────────────────────┤
│ 样张轮播             │
│ ┌─────────────────┐ │
│ │                 │ │
│ │      图片        │ │
│ │                 │ │
│ └─────────────────┘ │
│ 作者参考图 / 我拍摄  │
├─────────────────────┤
│ 阴天冷调日系         │
│ 常用                │
│ 富士 X-H2 / X100V    │
│ 阴天 街拍 冷调 胶片  │
├─────────────────────┤
│ 参数                │
│ 胶片模拟             │
│ Classic Chrome      │
│                     │
│ 动态范围             │
│ DR400               │
│                     │
│ 白平衡               │
│ Auto, R -2 / B +3    │
│                     │
│ 高光                 │

├─────────────────────┤
│ 来源截图             │

```

### 参数展示原则

- 使用纵向菜单列表，不使用表格。
- 参数名和参数值分两行，保证手机上可读。
- 空字段默认隐藏。
- 可疑或未确认字段可以标记为「待确认」。
- 提供「复制参数」操作，一键复制当前配方的完整参数文本。

### 已确认决策

- 参数页需要一键复制全部参数。

### 待确认点

- 样张轮播是否第一版就做，还是先展示封面 + 缩略图。
- 原始截图是否在详情页直接展示缩略图。

## 7. 页面四：新建 / 编辑配方页

### 页面目标

支持两种录入方式：

- 从截图开始，OCR 辅助识别。
- 从空白模板开始，完全手动填写。

### 推荐流程

第一版建议使用分段式单页，而不是多步骤向导。原因是用户可能只想先粗略保存，不想被强制完成每一步。

### 信息优先级

1. 配方名称。
2. 品牌。
3. 适配机型。
4. 样张。
5. 原始截图和 OCR 文本。
6. 标签。
7. 品牌参数模板。
8. 备注和状态。

### 低保真结构

```text
┌─────────────────────┐
│ < 返回        保存   │
├─────────────────────┤
│ 基本信息             │
│ 配方名 [__________]  │
│ 品牌   [富士 v]      │
│ 机型   [X-H2][X100V] │
├─────────────────────┤
│ 样张                │
│ [上传样张]           │
│ 来源：我拍摄/作者参考 │
├─────────────────────┤
│ 来源截图             │
│ [上传截图] [OCR识别] │
│ 识别文本             │
│ [                  ] │
├─────────────────────┤
│ 标签                │
│ 晴天 阴天 蓝调 ...   │
├─────────────────────┤
│ 参数                │
│ 胶片模拟 [________]  │
│ 动态范围 [________]  │
│ 白平衡   [________]  │
│ ...                 │
├─────────────────────┤
│ 备注                │
│ [                  ] │
└─────────────────────┘
```

### 保存规则

- 配方名称和品牌必填。
- 样张、截图、参数可以先为空。
- 配方状态只有「想试 / 常用」，新建配方默认「想试」。
- OCR 失败也允许保存截图和文本。
- 保存成功后回到快查页。

### 已确认决策

- 新建 / 编辑页采用分段式单页。
- 保存后回到快查页。

### 待确认点

- 新建页是否默认从「上传截图」开始。
- 富士和理光参数字段是否需要分组。

## 8. 页面五：备份页

### 页面目标

保证本地工具的数据安全，支持完整导出和恢复。

### 信息优先级

1. 当前配方数量。
2. 本地存储说明。
3. 导出 JSON。
4. 导入 JSON。
5. 导入前覆盖提醒。

### 低保真结构

```text
┌─────────────────────┐
│ 备份                │
├─────────────────────┤
│ 当前数据             │
│ 17 个配方            │
│ 48 张样张            │
│ 22 张来源截图        │
├─────────────────────┤
│ 本地浏览器保存       │
│ 换设备或清浏览器数据 │
│ 可能导致内容丢失。   │
├─────────────────────┤
│ [导出完整 JSON]      │
│ [导入 JSON 恢复]     │
└─────────────────────┘
```

### 已确认决策

- JSON 导入时覆盖当前数据，不做合并。

### 待确认点

- 第一版图片是否直接放进 JSON。

## 9. 主要用户路径

### 路径 A：出门快查

```text
打开应用
-> 选择富士 / 理光
-> 选择当前场景
-> 看样张瀑布流
-> 点开配方
-> 按菜单列表调整相机参数
```

### 路径 B：保存网上配方

```text
新建
-> 选择品牌
-> 上传参考样张
-> 上传原始截图
-> OCR 识别
-> 手动修正参数
-> 打标签
-> 保存
```

### 路径 C：手动创建自己的配方

```text
新建
-> 输入名称
-> 选择品牌和机型
-> 手动填写参数
-> 上传样张
-> 保存
```

### 路径 D：备份恢复

```text
备份
-> 导出 JSON
-> 保存到本地或云盘

备份
-> 导入 JSON
-> 确认覆盖当前数据
-> 恢复配方
```

## 10. 下一轮 UI 设计确认点

进入高保真 UI 前，需要确认：

- 产品气质：专业相机工具感，还是私人摄影笔记感。
- 首页是否需要更像相册，还是更像参数快查面板。
- 色彩是否偏真实摄影器材：黑、银、白、胶片纸色，还是更轻柔的日常笔记风。
- 配方卡片是图片占绝对主导，还是图片 + 信息均衡。
- 样张轮播第一版做轮播，还是封面 + 缩略图。
- 来源截图在详情页直接展示缩略图，还是只提供查看入口。
