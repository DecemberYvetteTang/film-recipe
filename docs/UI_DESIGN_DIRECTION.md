# Film Recipe UI 设计方向

## Figma 文件

- UI 初稿文件：[Film Recipe UI Draft](https://www.figma.com/design/b4cE1uGD9RrwC2Z7h4UYy1)
- 初稿范围：快查页、配方详情页、新建配方页。
- 生成日期：2026-07-30。
- 最近调整：根据用户反馈将风格向「文艺、手写摄影笔记」方向微调；底部导航由黑色工具栏改为浅色纸感；快查页新增明确的当前品牌切换入口；新建页拆分「效果样张」和「读取参数截图」。

## 1. 设计结论

第一版推荐方向：

> Contact Sheet Notebook：像一册随身携带的摄影接触印相本，但保留相机菜单的清楚和克制。

Film Recipe 不是营销页，也不是社交相册。它的第一屏要服务外出拍摄时的快速判断：先看样张，再看标签，最后进入参数。视觉上应该让照片成为主角，界面本身安静、专业、轻量。

## 2. 设计对象

具体对象：

- 产品：Film Recipe。
- 用户：个人摄影爱好者，主要使用富士和理光相机。
- 场景：出门拍摄时用手机快速查找直出配方。
- 页面任务：在 10 秒内通过品牌、场景、样张找到想用的配方。

## 3. 气质关键词

- 私人摄影笔记
- 相机菜单
- 接触印相
- 手写笔记感
- 外出快查
- 安静但不冷淡
- 清晰、克制、样张优先

不做：

- 不做营销型 hero。
- 不做过度装饰。
- 不做卡片套卡片。
- 不做大面积单色渐变。
- 不做像通用 SaaS dashboard 的界面。

## 4. 色彩系统

推荐色彩以相机机身、镜头镀膜、接触印相纸和红色记录标记为来源。

```text
Ink Black       #161816  主要文字、底部导航、强调按钮
Viewfinder Gray #5D625D  次级文字、边界、菜单辅助信息
Paper White     #F4F2EA  页面底色，类似相纸但不偏黄
Chrome Silver   #C8CCC7  分割线、禁用态、浅控件边框
Fuji Green      #2F5F50  富士品牌、常用状态、选中态之一
Ricoh Red       #C94335  理光品牌、重要操作、来源标记
Blue Hour       #2F536B  蓝调场景、夜晚标签、冷调风格
```

使用原则：

- 页面底色以 `Paper White` 为主，但不要做成温暖复古海报。
- 文字和导航用 `Ink Black`，保证户外查看时对比足够。
- 富士和理光可以有品牌色提示，但不让品牌色统治整个界面。
- `Ricoh Red` 只用于关键标记，不用于大面积背景。
- 场景标签可以使用轻微色彩差异，但卡片内颜色数量要收敛。
- 底部导航使用浅色纸感，不使用黑色工具栏。
- 可以使用少量手绘下划线、纸张边线和轻微不规则标记增加笔记感。

## 5. 字体方向

第一版优先使用系统字体，避免加载外部字体影响 PWA 首屏。

```text
Display / App title:
  ui-serif, "Songti SC", "Noto Serif CJK SC", serif

Body / Interface:
  Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif

Data / Camera params:
  "SF Mono", "Roboto Mono", ui-monospace, monospace
```

使用原则：

- 标题可以有一点摄影笔记感，但不要像杂志封面。
- 参数值使用等宽字体，帮助用户边看手机边调相机。
- 按钮和标签使用无衬线，保持清晰。
- 不使用随视口变化的字体大小。
- 不使用负字距。

桌面不做复杂管理后台。使用居中的手机宽内容或双栏补充信息：

## 7. 组件设计原则

### 品牌入口

- 富士 / 理光使用大按钮，不使用下拉框作为第一入口。
- 品牌卡显示机型和配方数量。
- 品牌卡不使用复杂插画，必要时使用相机图标和品牌色边线。

### 快查页

- 快查页要像看片，不像填筛选表。
- 快查页顶部必须有明确的「当前品牌 / 切换品牌」入口。
- 场景和题材标签直接展开。
- 风格标签默认折叠，只露出一个入口，例如「风格」或当前选中风格。
- 顶部提供「清空筛选」。
- 列表排序默认常用优先，其次按更新时间。

### 配方卡片

卡片结构：

```text
┌──────────────┐
│ 封面样张      │
│              │
├──────────────┤
│ 配方名        │
│ 常用 / 想试   │
│ 阴天 街拍 胶片 │
│ 作者参考图     │
└──────────────┘
```

设计原则：

- 图片占卡片最大面积。
- 文字只保留决策信息。
- 卡片圆角不超过 8px。
- 不在卡片里展示完整参数。
- 「常用」比「想试」更显眼，但不要抢过图片。

### 配方详情

- 顶部固定返回、复制参数、编辑。
- 样张展示采用封面 + 缩略图。
- 来源截图只展示「查看来源截图」入口，点击后打开图片预览。
- 参数按品牌分组，像相机菜单一样纵向排列。

富士参数分组建议：

- 色彩基底：胶片模拟、动态范围、D 范围优先级。
- 色彩效果：颗粒效果、色彩效果、彩色 FX 蓝色。
- 白平衡：白平衡模式、白平衡偏移 R/B。
- 曲线与细节：高光、阴影、色彩、锐度、高 ISO 降噪、清晰度。
- 拍摄建议：曝光补偿、ISO 建议、备注。

理光参数分组建议：

- 图像控制：图像控制、饱和度、色相、高低调。
- 对比与细节：对比度、对比度高光、对比度阴影、锐度。
- 画面修饰：明暗调整、周边光量。
- 白平衡：白平衡、白平衡偏移。
- 拍摄建议：曝光补偿、ISO 建议、备注。

### 新建 / 编辑

- 默认从基础信息开始。
- 使用分段式单页。
- 效果样张和参数截图分区展示。
- 效果样张用于展示配方风格，可以不上传。
- 参数截图用于 OCR 识别和来源留存，可能只有参数，没有照片。
- 上传截图和 OCR 放在效果样张之后。
- 参数字段按品牌分组。
- 保存后回到快查页。

### 备份页

- 明确区分「导出配方 JSON」和「导出图片包」。
- JSON 导入会覆盖当前数据，必须有确认提示。
- 第一版不做合并导入。

## 8. 标志性设计元素

推荐一个可记住的视觉元素：

> Contact Strip：配方详情页和快查页使用一条缩略图接触条，像胶片接触印相，但不做胶片齿孔装饰。

这个元素来自摄影工作流本身：先看一排小图，再决定哪张值得打开。它能服务功能，而不是单纯装饰。

## 10. 自检

### 是否像模板

风险点：

- 相纸白 + 摄影产品容易变成泛复古风。
- 黑色界面 + 红色点缀容易变成通用相机品牌页。
- 瀑布流容易像普通图片收藏工具。

修正：

- 不做大 hero，不做复古海报排版。
- 页面结构以快查和相机菜单为核心。
- 用 `Contact Strip` 作为功能性视觉元素。
- 参数区使用等宽字体和分组菜单，和普通相册拉开差异。

### 是否适合第一版

适合。它没有依赖复杂动效或插画资源，能先在 React 页面里快速实现，同时为后续 PWA 和真实样张保留空间。

## 11. 待用户确认

进入高保真 UI 前，请确认以下方向：

- 快查页品牌切换入口是否足够清楚。
- 当前浅色底部导航是否比黑色工具栏更接近预期。
- 新建页「效果样张」和「读取参数截图」的拆分是否符合使用习惯。
- 文艺、手写摄影笔记感是否还需要再加强。
- 详情页参数区是否需要继续加大留白。
