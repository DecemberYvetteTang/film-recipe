## 2026-07-29

### 今日完成

- 确认本地 `main` 已和 `origin/main` 对齐，GitHub 同步完成。
- 运行 `npm run lint`，TypeScript 检查通过。
- 运行 `npm run build`，生产构建通过。
- 创建本地初始提交：`Initial Film Recipe project`。
- 确认远程仓库地址：`https://github.com/DecemberYvetteTang/film-recipe.git`。
- 新增第一版低保真原型文档，覆盖品牌入口、快查页、详情页、新建 / 编辑页和备份页。
- 根据用户反馈收敛第一版原型决策，并同步更新产品文档、TODO 和类型定义。

### 今日决策

- 第一版保留 3 个底部入口：快查、新建、备份。
- 新建 / 编辑页采用分段式单页，避免强迫用户完成完整向导。
- 配方卡片只展示样张、名称、状态、少量标签和样张来源，不展示完整参数。
- 配方详情页隐藏空参数字段，可疑字段标记为待确认。
- 第一版默认进入品牌入口页，不记忆上一次品牌。
- 快查页风格标签默认折叠，仅保留一个可见入口。
- 配方详情页需要一键复制全部参数。
- 新建配方保存后回到快查页。
- JSON 导入采用覆盖当前数据，不做合并。
- 第一版不加入模拟数据。
- 配方状态只保留「常用 / 想试」。
- 快查页需要清空筛选按钮。
- 快查页需要常用优先排序。
- 样张展示采用封面 + 缩略图，不做轮播。
- 来源截图只提供查看入口，点击后预览图片。
- 新建页默认从基础信息开始。
- 富士和理光参数字段需要分组。
- 图片不直接放进 JSON 备份。
- 图片字段改为通过 `assetId` 引用，避免备份 JSON 内嵌图片数据。

### 下一步

- 确认 UI 视觉方向后进入高保真设计稿。
