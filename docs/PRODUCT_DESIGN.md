# Film Recipe 产品设计文档

## 1. 产品定位

Film Recipe 是一个手机优先、本地存储、以样张快查为核心的相机直出配方管理工具。

它主要服务个人摄影场景，帮助用户收藏、整理和快速查看富士、理光相机的直出参数配方，并通过样张、场景标签和风格标签，在出门拍摄时快速选择合适的参数。

## 2. 核心目标

第一版目标不是做社区，也不是做完整摄影日志，而是解决一个具体问题：

> 当用户出门拍照时，可以在 10 秒内根据当前环境和样张找到想用的相机配方。

## 3. 目标用户

- 喜欢拍照。
- 使用富士、理光等可自定义直出参数的相机。
- 经常从小红书等平台收集滤镜参数。
- 习惯用截图保存参数。
- 出门时主要用手机查看参数。
- 更依赖样张视觉效果来决定使用哪组配方。

## 4. 使用场景

用户在网上看到一组喜欢的相机直出参数，截图保存，并导入 Film Recipe。

用户可以上传原始截图、参考样张，使用 OCR 辅助识别参数，再手动修正并保存为一条配方。

出门拍照时，用户打开 Film Recipe，先选择品牌，再按场景、题材、风格筛选，通过样张瀑布流快速选择配方，点进详情页查看相机菜单式参数。

## 5. MVP 功能范围

第一版包含：

- 品牌选择：富士 / 理光。
- 配方管理：新增、编辑、删除、查看。
- 固定品牌参数模板。
- 样张上传，并标注来源：我拍摄 / 作者参考图。
- 原始截图上传与保存。
- OCR 识别截图文字。
- OCR 结果手动修正。
- 场景标签筛选。
- 题材标签筛选。
- 风格标签筛选。
- 样张瀑布流。
- 配方详情页。
- 本地浏览器存储。
- JSON 导入 / 导出备份。

第一版不做：

- 用户登录。
- 云同步。
- 社区分享。
- AI 自动推荐。
- 拍摄日志。
- 地图记录。
- 天气自动识别。
- 相机连接同步。
- 多人协作。

## 6. 信息架构

主要页面：

- 品牌选择页：用户先选择富士或理光。
- 首页 / 快查页：展示场景、题材、风格筛选项，以及样张瀑布流。
- 配方详情页：展示样张、适配机型、标签、相机菜单式参数、来源截图、备注。
- 新建 / 编辑配方页：支持手动填写参数、上传样张、上传截图、OCR 识别。
- 备份页：支持导出完整 JSON 文件，或从 JSON 文件恢复数据。

## 10. 关键交互原则

- 样张优先，参数第二。
- 打开应用后先选品牌。
- 首页使用瀑布流展示样张。
- 配方详情页使用相机菜单列表样式，不使用复杂表格。
- OCR 只作为辅助，不要求全自动准确。
- 所有 OCR 识别内容都必须允许手动修改。
- 原始截图必须保留，作为参数来源证据。
- 不强迫用户拍完后记录。

## 11. 成功标准

- 用户是否愿意持续录入配方。
- 出门时是否真的会打开使用。
- 能否在 10 秒内通过样张找到想用的配方。
- 参数详情是否足够清晰，方便边看手机边调整相机。
- OCR 是否减少了录入成本，而不是增加负担。

## 12. 后续迭代方向

- 图片压缩与存储优化。
- JSON + 图片 ZIP 备份。
- PWA 离线访问。
- 常用配方置顶。
- 最近使用。
- 机型兼容性提示。
- iCloud / WebDAV / Supabase 同步。
- AI 根据截图自动生成初始配方草稿。
- 社区配方分享。
- 用户公开主页。
- 多品牌支持。

## 13. 第一版一句话

Film Recipe 是一个给自己用的相机直出配方库，用样张帮你快速决定今天该用哪组参数。
