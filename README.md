# Film Recipe

手机优先的相机直出配方快查笔记。

Film Recipe 用于收藏、整理和快速查看富士、理光相机的直出参数配方。第一版目标是让用户在出门拍照时，可以根据品牌、场景、题材和样张，在 10 秒内找到想用的配方。

## 开发命令

```bash
npm install
npm run dev
npm run build
```
